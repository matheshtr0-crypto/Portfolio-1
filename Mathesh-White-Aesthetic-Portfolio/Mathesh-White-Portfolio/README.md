# Mathesh T.R. — Professional Portfolio

A responsive, white-background personal portfolio built with HTML, CSS and vanilla JavaScript.

## Project structure

```text
Mathesh-White-Portfolio/
├── index.html
├── README.md
└── assets/
    ├── mathesh-formal.jpg
    ├── mathesh-portrait.jpg
    └── Mathesh-Resume.pdf
```

## Run locally

1. Extract the ZIP.
2. Keep `index.html` and the `assets` folder together.
3. Open `index.html` in a browser.

No npm install, build command, backend or database is required.

## Deploy with GitHub and Vercel

1. Create or open a GitHub repository.
2. Upload `index.html`, `README.md`, and the complete `assets` folder to the repository root.
3. In Vercel, select **Add New → Project** and import the repository.
4. Set Framework Preset to **Other**.
5. Leave Build Command empty.
6. Set Output Directory to `.` (or leave the default root setting if Vercel accepts it).
7. Deploy.

## Before publishing

- Confirm the two photos are the ones you want to show publicly.
- Open the resume download and confirm the PDF is current.
- Check the Wanderly and TaskFlow live links.
- Add a KALKI preview link only when a public URL is available.
- Add individual GitHub project links only when the correct repositories are confirmed.

## Notes

- The design uses a clean white layout, restrained blue accents, responsive navigation and lightweight scroll reveals.
- The site respects `prefers-reduced-motion`.
- No fabricated project URLs, client metrics or payment-gateway claims are included.
- Google Fonts is loaded from Google Fonts; if unavailable, system sans-serif fonts are used.
